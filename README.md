# 🚤 Hangkai 30 HP NMEA 2000 Gateway & Web Dashboard

Этот проект представляет собой DIY-шлюз для подключения подвесного лодочного мотора Hangkai 30 л.с. (или аналогичного «глупого» мотора) к современной сети **NMEA 2000**. 

Устройство считывает аналоговые сигналы с датчиков двигателя, преобразует их в стандартные PGN-сообщения NMEA 2000 (для картплоттера) и одновременно транслирует данные на красивый **веб-дашборд** для смартфона по Wi-Fi.

## ✨ Основные возможности
*   **Передача данных в NMEA 2000:** Обороты двигателя (RPM), температура, напряжение бортсети.
*   **Веб-интерфейс:** Доступ к телеметрии в реальном времени с любого смартфона или планшета через браузер (без установки приложений).
*   **Подсчет моточасов:** Автоматический учет времени работы двигателя.
*   **Совместимость:** Работает с любыми картплоттерами и дисплеями, поддерживающими стандарт NMEA 2000 (Garmin, Lowrance, Raymarine, Simrad и др.).

## 🛠️ Аппаратное обеспечение

| Компонент | Описание |
| :--- | :--- |
| **Микроконтроллер** | ESP32-S3-DevKitC-1 N16R8 (16MB Flash, 8MB PSRAM) |
| **CAN-трансивер** | MCP2562 (или MCP2562FD) |
| **Датчик температуры** | Термистор NTC 10 кОм (закрепляется на головке блока цилиндров) |
| **Резисторы** | Для делителя напряжения (например, 10 кОм и 2.2 кОм) и подтяжки термистора (10 кОм) |
| **Питание** | Понижающий DC-DC преобразователь (12В -> 5В) |
| **Прочее** | Терминаторы NMEA 2000 (2 шт. по 120 Ом), разъемы, провода |

## 🔌 Схема подключения

### 1. Подключение CAN-трансивера MCP2562 к ESP32-S3
> ⚠️ **КРИТИЧЕСКИ ВАЖНО:** Вывод `VIO` (пин 5) MCP2562 должен быть подключен к **3.3В** на ESP32-S3, чтобы согласовать логические уровни. Подача 5В на VIO повредит микроконтроллер!

| ESP32-S3 | MCP2562 | Примечание |
| :--- | :--- | :--- |
| **GPIO 5** | TXD (пин 1) | Передача данных (CAN TX) |
| **GPIO 4** | RXD (пин 4) | Прием данных (CAN RX) |
| **3.3V** | VIO (пин 5) | **Питание логики (3.3В!)** |
| **5V** | VDD (пин 3) | Питание трансивера |
| **GND** | GND (пины 2, 8) | Общий провод |
| **CANH** (пин 7) | -> | Линия CAN_H шины NMEA 2000 |
| **CANL** (пин 6) | -> | Линия CAN_L шины NMEA 2000 |

### 2. Подключение датчиков
| Пин ESP32-S3 | Датчик | Схема подключения |
| :--- | :--- | :--- |
| **GPIO 1** (ADC1_CH0) | **Обороты (RPM)** | Сигнал снимается с клеммы "W" генератора или катушки зажигания. **Обязательно** используйте делитель напряжения и стабилитрон на 3.3В для защиты пина! |
| **GPIO 2** (ADC1_CH1) | **Температура** | Термистор NTC 10кОм подключается между пином и GND. Резистор 10кОм подключается между пином и 3.3В. |
| **GPIO 3** (ADC1_CH2) | **Напряжение** | Делитель напряжения из бортсети 12В. Например, 10кОм (к +12В) и 2.2кОм (к GND), средняя точка — на пин GPIO3. |

## 💻 Программное обеспечение

### Настройка среды (macOS)
1.  Установите **Visual Studio Code** и расширение **PlatformIO IDE**.
2.  Установите драйвер USB-UART (CP210x или CH340) в зависимости от чипа на вашей плате ESP32-S3.
3.  Создайте проект PlatformIO для платы `esp32-s3-devkitc-1`.

### Настройка `platformio.ini`
Ваш файл `platformio.ini` должен содержать следующие параметры для корректной работы платы N16R8 и библиотек:

```ini
[env:esp32-s3-devkitc-1]
platform = espressif32
board = esp32-s3-devkitc-1
framework = arduino
monitor_speed = 115200

; Настройки для N16R8 (16MB Flash / 8MB PSRAM)
board_build.arduino.memory_type = qio_opi
board_build.flash_mode = qio
board_build.psram_type = opi
board_upload.flash_size = 16MB
board_upload.maximum_size = 16777216
board_build.partitions = default_16MB.csv
build_flags = -DBOARD_HAS_PSRAM

lib_deps =
    https://github.com/ttlappalainen/NMEA2000.git
    https://github.com/jiauka/NMEA2000_esp32xx.git
    ESP-DashboardPlus
```

### Структура проекта
*   `src/main.cpp` — Основной код прошивки.
*   `src/dashboard_html.h` — Заголовочный файл с минимальным HTML для дашборда.
*   `platformio.ini` — Конфигурация сборки.

## ⚙️ Настройка и калибровка кода

Перед прошивкой обязательно отредактируйте следующие параметры в `main.cpp`:

1.  **Wi-Fi:** Укажите ваш SSID и пароль.
    ```cpp
    const char* ssid = "YOUR_WIFI_SSID";
    const char* password = "YOUR_WIFI_PASSWORD";
    ```
2.  **Коэффициент делителя напряжения (`VOLTAGE_DIVIDER_RATIO`):** Рассчитайте по формуле `(R1 + R2) / R2`. Если R1 = 10к, R2 = 2.2к, то коэффициент ≈ 5.54.
3.  **Импульсы на оборот (`PULSES_PER_REV`):** Зависит от генератора. Начните со значения `6` и корректируйте, сверяя показания с эталонным тахометром.
4.  **Параметры термистора:** Если вы используете другой термистор, измените константы `TEMP_NOMINAL_RES`, `TEMP_BETA` и `SERIES_RESISTOR`.

## 📡 Передаваемые PGN (NMEA 2000)
Устройство отправляет следующие стандартные сообщения:
*   **PGN 127488** (Engine Parameters, Rapid Update): Обороты двигателя (RPM).
*   **PGN 127489** (Engine Parameters, Dynamic): Температура двигателя и напряжение бортсети.

## 📱 Использование веб-дашборда
1.  После прошивки и включения питания подключите смартфон к той же сети Wi-Fi, что и ESP32.
2.  Откройте монитор порта (Serial Monitor) в PlatformIO и дождитесь появления IP-адреса (например, `192.168.1.100`).
3.  Введите этот IP-адрес в браузере смартфона. Вы увидите дашборд с показаниями RPM, температуры, напряжения и моточасов в реальном времени.

## ⚠️ Меры предосторожности
*   Лодочная электрика подвержена помехам. Используйте экранированные провода для сигнальных линий (особенно для RPM).
*   Убедитесь, что вся схема надежно заизолирована и защищена от влаги.
*   Не подключайте пины ESP32-S3 напрямую к 12В — используйте делители напряжения и защитные диоды!
*   Для стабильной работы сети NMEA 2000 на обоих её концах (backbone) должны быть установлены терминаторы по 120 Ом.
